# bf-5206 — Gate mock_claude Stop on prompt receipt (no EC-7 misfire on happy stream-json path)

## Outcome
Fixed and verified. The stream-json (and text) happy-path mock run no longer trips
the EC-7 backstop in `session.rs` (~line 688, the `FifoPayload` arm). All three
acceptance criteria pass. No production code changed — this is a mock-only fix
(real Claude Code never fires Stop before injection; EC-11 in `pty.rs` unsets the
session-id env before exec).

## The bug
mock_claude fired the Stop hook on a fixed code path regardless of input. In driven
mode claude-print's startup sequencer reaches `PROMPT_INJECTED` only after a
~2.0s idle gap past trust-dismiss, so Stop routinely landed *before* injection and
the EC-7 defense-in-depth check fired on every happy run:

> `Stop hook fired before prompt was injected (EC-7: response to an unsent prompt ...)`
> → exit 2 / `is_error:true` / `subtype internal_error`, no streamed transcript.

## The fix (`test-fixtures/mock-claude/src/main.rs`)
Made the mock faithful to real Claude Code in **claude-print-driven mode**
(detect `--settings=` in argv), while leaving the legacy direct-spawn mode (raw
FIFO round-trip, no sequencer) unchanged:

1. **Trust dialog on by default** — `MOCK_TRUST_DIALOG` now uses
   `env_bool_default(..., true)` (unset ⇒ on), so the scanner sees trust keywords
   and can reach `PROMPT_INJECTED`. Only emitted in driven mode.
2. **Gate Stop on actual prompt receipt** — new `wait_for_prompt()` blocks reading
   stdin until the bracketed-paste close marker `ESC[201~` arrives (claude-print
   delivers the prompt as `ESC[200~ … ESC[201~` + CR; the trailing CR flushes the
   canonical-mode line so the marker arrives intact). The trust-dismiss CR is
   consumed and ignored. Only the close marker unblocks Stop.

Both are **skipped under `MOCK_STOP_BEFORE_INJECT`** so the deliberate EC-7
negative fixture still wins the race and trips the backstop — the EC-7 guard is
not weakened.

## Verification
- **AC1 (no EC-7 on happy stream-json path):** direct run
  `claude-print --claude-binary <mock> --output-format stream-json --verbose …`
  traces `phase transition: trust-dismissed -> prompt-injected` (2005ms) →
  `prompt injected` → `stop received` (2005ms, *after* injection) → **EXIT 0**.
  Reader spawns (no "could not derive projects dir" warning). The non-ignored
  regression guard `stream_json_mode_exit0_each_line_valid_json` (asserts exit 0)
  **passes** — it would be exit 2 under EC-7.
- **AC2 (genuine pre-inject Stop still caught):** both `binary_e2e`
  `ec7_stop_before_inject_*` tests pass (exit 2 / `is_error:true` /
  `subtype internal_error`).
- **AC3 (no lib-test regression):** `cargo test --lib` → **128 passed; 0 failed**.
